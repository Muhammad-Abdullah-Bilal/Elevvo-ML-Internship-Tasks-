# Forest Cover Type Prediction using Tree-Based Models

## 📌 Project Overview
This project is part of my internship task focused on **multi-class classification**
using **tree-based machine learning models**.
The objective is to predict the **type of forest cover**
based on cartographic and environmental features.

## 🧠 Covered Topics
- Multi-class Classification
- Tree-Based Modeling
- Data Preprocessing
- Model Evaluation
- Feature Importance Analysis

## 🛠 Tools & Libraries
- Python
- Pandas
- Scikit-learn
- Matplotlib
- Seaborn

## 📂 Dataset
**Covertype Dataset** from :contentReference[oaicite:0]{index=0}  
The dataset contains environmental features such as elevation, slope,
soil type, and wilderness area indicators.

## 🔄 Workflow
1. Load dataset using Scikit-learn
2. Explore dataset structure and target distribution
3. Separate features and target variable
4. Split data into training and testing sets
5. Apply feature scaling
6. Train Random Forest classifier
7. Evaluate model using accuracy and classification report
8. Visualize confusion matrix
9. Analyze feature importance

## 🌲 Model Used
- Random Forest Classifier (Tree-Based Model)

## 📊 Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- Confusion Matrix

## 📈 Results
The Random Forest model achieved strong performance
in predicting forest cover types across multiple classes.
Feature importance analysis revealed elevation and soil-related
features as the most influential predictors.
