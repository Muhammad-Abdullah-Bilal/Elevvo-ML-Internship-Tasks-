# Mall Customer Segmentation using Clustering

## 📌 Project Overview
This project is part of my internship task focused on **unsupervised learning**.
The objective is to segment mall customers based on their **annual income**
and **spending score** using clustering techniques.

## 🧠 Covered Topics
- Clustering
- Unsupervised Learning
- Feature Scaling
- Cluster Evaluation

## 🛠 Tools & Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## 📂 Dataset
**Mall Customer Dataset** from :contentReference[oaicite:0]{index=0}  
The dataset contains customer demographic and spending information.

## 🔄 Workflow
1. Load and explore dataset
2. Select relevant features
3. Scale features
4. Visualize customer distribution
5. Determine optimal clusters using Elbow Method
6. Apply K-Means clustering
7. Visualize customer segments
8. Analyze average spending per cluster
9. Apply DBSCAN clustering
10. Compare clustering results

## 📊 Algorithms Used
- K-Means Clustering
- DBSCAN Clustering

## 📈 Evaluation
- Elbow Method
- Silhouette Score
- Cluster-wise spending analysis

## ▶ How to Run
1. Open Google Colab
2. Upload `Mall_Customers.csv`
3. Run all cells step by step

## ✅ Conclusion
K-Means effectively segmented customers into clear spending groups,
while DBSCAN identified dense customer regions and noise.
This analysis helps businesses understand customer behavior
and improve marketing strategies.
