# Student Exam Score Prediction using Linear Regression

## 📌 Project Overview
This project is part of my internship task where I built a machine learning model
to predict students' exam scores based on their study hours using **Linear Regression**.

## 🧠 Concepts Covered
- Supervised Learning (Regression)
- Data Cleaning
- Data Visualization
- Train-Test Split
- Model Evaluation

## 🛠 Tools & Libraries
- Python
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn

## 📂 Dataset
**Student Performance Factors Dataset (Kaggle)**  
The dataset contains information related to students' study hours and exam scores.

## 🔄 Workflow
1. Load and explore the dataset
2. Clean missing values
3. Perform exploratory data analysis (EDA)
4. Split data into training and testing sets
5. Train a Linear Regression model
6. Predict exam scores
7. Evaluate model performance
8. Visualize predictions

## 📊 Evaluation Metrics
- Mean Absolute Error (MAE)
- Mean Squared Error (MSE)
- Root Mean Squared Error (RMSE)
- R² Score

## 📈 Results
The model successfully learned the relationship between study hours and exam scores.
A positive linear trend was observed, indicating that increased study hours generally
lead to higher exam scores.

## ▶ How to Run
1. Open Google Colab
2. Upload the dataset (`student_performance.csv`)
3. Run cells step-by-step

## ✅ Conclusion
This project demonstrates a complete machine learning pipeline using regression
and provides insights into how study time impacts academic performance.
